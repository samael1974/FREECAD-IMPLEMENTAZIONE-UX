# Installare SolidFlow UX su Windows

Serve FreeCAD 1.1.x già installato. Questa è una **versione sperimentale per tester**.

1. [Scarica il setup Windows](https://github.com/samael1974/FREECAD-IMPLEMENTAZIONE-UX/releases/download/v0.4.0-beta.13-test.3/SolidFlowUX-Setup-v0.4.0-beta.13-test.3.exe).
2. Chiudi FreeCAD e avvia il file `.exe` scaricato.
3. Segui il setup; per FreeCAD 1.1 con profilo standard lascia la cartella proposta.
4. Riapri FreeCAD: trovi il menu **SolidFlow**. Premi **S** nella vista 3D.

Non serve un account GitHub. Non scaricare “Source code”: sono i sorgenti per sviluppatori.
SolidFlow è un'estensione di FreeCAD, non un programma separato o un nuovo workbench.

Per FreeCAD portabile o profili personalizzati, consulta le istruzioni alternative nella
[pagina di download](https://github.com/samael1974/FREECAD-IMPLEMENTAZIONE-UX/releases/tag/v0.4.0-beta.13-test.3).
La versione di prova ha superato i test automatici e l'installazione Windows;
le prove native FreeCAD sono ancora da completare. Usa copie dei tuoi progetti.

Se l'installazione non riesce, invia il messaggio esatto. Se manca il menu SolidFlow,
riavvia completamente FreeCAD e apri la guida dal menu Start > SolidFlow UX.
