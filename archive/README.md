# Archivio SolidFlow UX

Questa cartella contiene file storici conservati per confronto, audit e recupero.

**Non fanno parte del runtime corrente e non vengono inclusi nell'installer.**

- `legacy-runtime/` — vecchi layer beta sostituiti dal core consolidato
- `legacy-updaters/` — vecchi updater BAT basati su download raw GitHub
- `tests/` — checklist di collaudo delle beta precedenti

Per installare SolidFlow UX usare la pagina **Releases** del repository.
Per controllare o compilare il progetto localmente usare `CHECK_SOURCE.ps1` e `BUILD_INSTALLER_LOCAL.ps1` nella radice del repository.
